## 来源与共用母版

参考图 SHA256 为 `f84c8c750a3f471b8fbc6692c6dc9cdf532493720e777af5914bd86098e2b99c`。原图中的手仅用作尺寸与持物方向提示；制作复用 CHAR070 的皮肤和指甲，不新增手部母版。所有来源文件保留，移除旧半掌皮套与腕扣的裸手为明确的派生件。

CHAR182 保存 `primaryMasterId: LIFE-046`，空碗逐格占用、原点和 10mm 格距与主母版一致。`ceramicWhite → heldCeramic`、`ceramicTeal → heldCeramicGlaze` 为显式语义映射，使角色视觉层保持非碰撞；并非重命名或修改原碗材质。餐食形态仅添加汤汁、豆腐和叶菜，原碗占用不变。资源包包含原 LIFE046 文件及其导出依赖，图册、接口清单、库计数和包清单均标出共用关系。

LIFE074 的现成资产是有刚架、木框和石脚的回收容器，区别于本批软购物袋。LIFE047 的盘上方杯没有手柄，区别于本批有把、有独立盖的杯；LIFE196 是吸尘设备、推车与拖把，不作为扫帚重复引用。以上判断基于现成几何，不能仅按名字认为是同一物件。

## 材质与接口

新增 349–382 三十四种用途材质，全库三百五十六个角色，以 256 + 100 条在同一事务内创建。腰带皮革/软衬、牌底/印墨/背夹、伞纸/木杆/金属骨/织边、拐杆/握胶/脚胶/腋垫、购物布/带、包装纸/墨、食材、陶器釉层、筷木、金属勺头/木柄、扫帚纤维/束带/木柄与连接金属分开。角色物件全部非碰撞、零发光；已有相同用途角色按语义复用，不借相近颜色的材质。

除共用碗外，持物采用一个 prop 根关节。原生细件和连续表面保留绑定态；手部姿态只变换关节矩阵，不重新采样方格。斜勺柄的实际轴另存于 grip 元数据；核心接口仍使用规定的轴向法线。取下杯盖是独立摆放形态，没有虚构铰链。

## 有限安装研究

五组真实编辑器场景为 mobility、daily、utensils、belt、badge。伞、手杖、腋拐、购物袋、平行双筷、勺与扫帚分别使用七种作者手指姿态，检查真实皮肤/指甲与物件的三角面穿插，并测量皮肤到指定握柄的距离。至少两个皮肤分件须在 6mm 内；此距离检查不能代替手指软接触或载荷计算。杯、纸袋和餐碗使用三种张手掌根承托，核查掌面邻近与穿插，不称杯把抓握。双筷只验证平行束握，不声称进食动作。

腰带搭配实际 CHAR113/118 内搭、既有头发和手足，保留原覆衣身体并明确移除被替换衣面。成人 A/B 仅检查站姿和 20° 肩外展；衣服的老腰边与扣件保留，没有删去交叠对象掩盖问题。胸牌与腰牌采用 3mm 织带试片检查 4mm 背夹槽、上桥承接和开放入口；试片不是服装母版，也不是完整人物胸牌安装。

全几何连通检查包含每一个连续分件及每个原生方格岛。预期只有双筷的两个物件、取下盖的杯/盖两个物件保持分离。开口检查读取真实几何，覆盖腰孔、口袋底、袋底、纸袋底、原碗腔/底、杯把孔、杯腔/底/盖、勺腔与吊环。
