## 穿戴和来源

身体沿用 CHAR-059 / 060 的独立作者比例，头、短发、手足与鞋另存源母版。长礼服和飞行皮衣真正替换旧衣身及袖面；雨披、围巾、救生衣、支具及背包配 CHAR-113 上衣、CHAR-118 长裤和 CHAR-122 鞋，移除旧身体中被替换的衣面与裤腿。

绷带所配的裸躯干与裸臂，来自原覆衣身体的同源轮廓，作为明确的作者皮肤派生件保存；不是原游戏裸体网格。手套配 CHAR-070 的原皮肤和指甲，派生手只移除旧半掌皮套、腕圈及原生腕扣，原完整手另存。镜像保留真实面绕序与格子映射。

礼服默认肩外展 20°，其余身体组合为 8°。本批身体穿戴只验证站姿；手套只验证张手。掌根与拇指近端使用共用刚性空腔，拇指末端单独绑定；不声称完整拇指屈曲或握持控制器。原生格保持绑定姿态，显示和 GLB 通过关节矩阵变换，不旋转后重新栅格化。

背包和挎包闭合穿戴仅验证成人 A，开盖单独离身展示。两件包使用 `prop` 类型、根关节与真实前铰轴，前加强襟固定，盖板、提环和卷毯随盖旋转。分别验证 0°、15°、30°、45°、60°、75°、90°、105° 八个角度。实际铰轴处的预期接触单独标注；其余包壳与固定肩带进行三角面检查。有限角度检查不代表任意连续动作的形式化证明。

## 材质和导出

新增 22 项用途角色，ID 327–348；全库 322 角色按 256 + 66 条在同一事务中创建。礼服布与织花、雨膜与接缝、围巾与流苏、皮革与橡胶护块、救生织壳与泡棉、飞行皮革与绒边、绷带、支具金属与软垫、旅行帆布与皮带、设备底壳与光学片分别归类。全部角色外观非碰撞；光学片未绑定供电，保持零发光。

雨膜参考外观透明度 0.48、接缝 0.88。透明度验证读取 GLB 对应 UV 的实际纹理像素并乘基色 alpha，不能只检查材质名。没有天气、防水、浮力、防护或医疗行为模拟。

配方检索尺寸已更正为各件默认姿态的实测边界；参数形态读取自身原生文件的实际尺寸。该元数据修正不改变几何哈希或已有导出。

24 种形态和七组装配输出原生文件、GLB、材质图集、接口及绑定数据。近远档只合并同关节的原生共面；连续网格保持不变。GLB 的 skin、逆绑定矩阵、关节索引和权重经过独立求值，再与实际姿态包围盒比较。M036 与 M037 的全部 46 种既有几何哈希保持不变。

七组场景为礼服、雨披/围巾、救生/飞行、绷带/支具、闭合背包穿戴、成人/儿童双侧手套、离身开盖。真实 MCP 请求按既有 9 MiB 限制分批传入，保留顺序；不能把多次场景安装事务称为整场景一次撤销。另查单次外观替换、儿童手套重建、实际包盖姿态重建的失败回滚和一次撤销。

初始裤腿、雨帽、指根、腕扣、背包肩带与开盖路径的失败记录随包保留。可见的肩袖硬接缝、简化的掌根护壳和固定背带仍需美术审查。没有软布、软权重、IK、动作片段或原骨架控制器绑定；原角色源码、尺寸矩阵及受保护净空未收件。软件 WebGL 截图不代表硬件帧率验收。
