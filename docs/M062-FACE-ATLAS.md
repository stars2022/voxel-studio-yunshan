# M062 六格面孔与共享贴图

六格共用一张 **192×16 RGBA PNG**，每格 32×16；原生文件和 GLB 都保存实际 UV 与贴图。三个年龄头型保留连续头壳、鼻、耳和颈的真实几何。原头部完整另存；派生头移除旧眼、眉、唇、皱褶的原生细格，保存删除明细、原 UV 和 chunk 顺序，可精确恢复原形。耳内最小块件仍为 5 mm，成人、老年、儿童分别保留 16、30、60 格，未把连续头壳重新栅格化。

皮肤、褶纹、唇、眼白、虹膜、瞳孔、眉毛、鬓发、稀疏灰鬓使用九个独立用途输入。灰鬓是既有用途的外观实例，不增加全库 512 种语义用途；外来材质 ID 不覆盖。修改肤色、虹膜或灰鬓会更新实际 GPU 贴图像素，几何和其他材质保持，撤销恢复原像素。GLB 使用受光 PBR 与最近邻采样，不借用天空或大气通道。

023 的原生材质资源含实际 PNG、用途像素映射、图谱描述与 GLB；1.92×0.16 m 平面仅用于展示整张材质，零原生格、非碰撞，不计作几何基础母版。六个面孔属于三种头型、六种 UV 配置，不是六个新人物。全部保持静态、非碰撞、零发光；当前近远档头型相同，没有自动距离切换。

原 `citizen-appearance.ts` 像素源码未提供，本图谱是依照六格合同制作的作者设计，不能声称逐像素复原。年龄和情绪条件保留为来源元数据，尚未绑定原角色控制器、自动表情切换或动画。参考图中的完整发型、冠饰和服装不在这批面孔 UV 范围内。

验证读取 18 份实际 GLB、12 次父件关系，覆盖新 023 材质和三种历史原头。浏览器通过六次公开创建及六次旋转/撤销，实测六头共用一个 GPU 贴图对象，换色与撤销的实际 RGBA 字节匹配。M062 的 36 张默认视图与 17 张 MCP 视图随包保存；逐张查看范围和全库回归结果见实际报告。
