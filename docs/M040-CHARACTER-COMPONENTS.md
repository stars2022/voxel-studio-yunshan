# M040 角色日用、诊疗与执勤持物候选

本批涵盖 CHAR187–198 十二个参考条目，新增十一件独立母版，CHAR189 显式引用既有 LIFE106。每件提供两种静态形态，共二十四种；未计入新的居民、手部或设备背景。人工美术验收为零。

最小扣件、织标、包角和实体按键采用 5mm 原生体素。布面折弯、器壁、弯管、斜颈、握胶和挂环采用连续网格。原始网格、原生占用、材质 ID 与米制接口均随资产保存；斜面不因体素风格被重新栅格化。

LIFE106 原文件、原索引行、原材质和导出依赖保留。CHAR189 合拢态仅将七种用途映射到非碰撞持物材质；展开态保持所有原生格的绑定坐标不变，上封面及页块绕作者指定的 Z 书脊旋转 180°，增添一条连续装帧内桥。该静态派生不代表原书已有翻页动画。固定书脊仍形成较高的中央条，属于待美术修整的旧装帧派生。原书直角页块和装帧层次仍属于旧造型，未冒称整件连续曲面重制。

三组作者场景共十二种有限手部配合：八种指定握柄握姿、终端和记录板两种背带内承托、抹布和书册两种掌根承托。每组保留原 CHAR070；裸手派生去除旧皮套与腕扣，指节保持刚性关节，不重新采样。实际皮肤、指甲与物件三角面检查穿插；八种握姿须至少两段皮肤距指定握柄小于 6mm，承托须掌面距离小于 6.1mm。配手场景仅验证各件默认形态；展开书、移盖和其他变体为离手静态展示。该条件是可复查的有限作者摆放，不能替代完整抓握控制器、摩擦、负载或全身动作验证。

新增 36 个用途角色（383–418），全库 392 个角色，按 256+136 分块在同一事务创建。抹布条带归织物，封皮/页芯/页边归各自纸用途；印墨不借塑料或屏幕。诊察胶管、耳塞、握胶与天线包胶独立，探头机壳与急救箱硬壳独立。玻璃罩、未绑定灯芯、显示底面和前光学片分别保存。全部角色持物为非碰撞、零发光；材质试作中提灯玻璃有效 alpha 为 0.24，清水为 0.60，均不等于真实透射或流体。

检查包括连续组件的闭合与面绕序、原生岛与实体表面的实际接触图、指定孔腔及底面、近远表面覆盖、完整用途映射、GLB 独立 CPU skin 求值、原生/接口/碰撞回读、材质替换失败回滚及一次撤销。原生表面需按实际刚体归属合并后判断实体内部；单个材质桶可能不是闭壳，不能独自作为实心判断依据。

现有边界：原游戏角色源码、尺寸矩阵、原骨架、库存、设备控制器和保护净空未收件。所有形态与接口均为作者候选；布料折形、胶管曲线和刚性指节仍待美术审阅。不声称软皮肤、IK、动态布料/胶管/水、医疗诊断、通信、电源或运行帧率通过。
