# M031：盆景与角色组件

延续用户修正：最小块件保留体素，斜面与曲面使用连续网格，适合贴图的效果使用贴图。角色扣件、眼眉和指甲采用 5 mm 原生块件；身体收腰、肢体锥度、指节、发束和衣摆保存米制连续三角面。盆景叶簇、土塞采用 40 mm 原生块件，枝根使用连续网格。斜置肢体没有重新栅格化。

皮肤、唇、指甲、皮肤褶线、眼白、虹膜、瞳孔、发干/发束、织物、织入纹样、金属护片、铜扣、皮革、鞋底橡胶、光学饰面和发带分别归类。耳内层及眼睑使用 skinCrease，不借唇部角色。角色全部材料和网格为非碰撞视觉层，包括金属护片和橡胶底；饰面光芯未绑定供电，默认零发光。材质包保留用途、实际 ID、碰撞、几何和自定义角色映射。

静态装配保留可编辑源母版、参数和每件刚体变换，展示网格由源母版派生。左右镜像重排三角形绕序；坐姿小腿竖直、袖臂绕肩轴旋转，腕部接口相合。肩轴法线和腰口尺寸通过实际编辑器 connect 事务验证，左侧镜像同步反转肩轴法线。导出的姿态是静态三角网格，没有蒙皮、动画或原运行时绑定。短发后片没有额前发型，完整精细发型对应后续 CHAR-085 等条目；这些样件不作为完整头像或成品角色验收。

333 项完整回归通过；后续修正另有 24 项角色/景观、22 项核心/几何、1 项外来材质 ID 专项通过。11 项真实 MCP 检查覆盖事务、撤销、缓存、重建、导出、五组装配和保存重启。36 张本批资产图、3 张依赖图、17 张装配图、5 张背面细节图已查看；头部用途材质修正后补拍三张并保留旧图。测试使用 SwiftShader 软件 WebGL。

格子检查只覆盖原生实体层；盆景连续实体网格的范围提示仍保留。纯视觉组件不因离开网格而触发虚假的物理失败，实体块与声明开口仍须满足精确格距检查。形体、细节密度与参考图的差距留待美术复核，不把技术检查视为人工美术通过。
