# M065–M066 人物与动物 LOD

本批交付 CHAR-357–364 八条参考、60 种手选形态，覆盖两个完整人物与 18 种动物。M065 达到 12/12，M066 达到 2/12；累计 782/793 条技术候选，剩余 11 条环境与家具参数变体。未新增基础母版、组合或语义材质，人工美术验收为 0。

| 参考 | 实际来源 | 形态 |
| --- | --- | --- |
| 357、358、359 | 完整 CHAR-001 成人装配 | 分别为近、中、远档 |
| 360 | 完整 CHAR-165 学生装配 | 近、中、远档，保留真实儿童比例 |
| 361 | 猫、犬、兔、猪、山羊、牛、鹿、野猪、松鼠 | 九种原身体各三档 |
| 362 | 小鸟、鸡、鸭、鹅、鹭 | 五种原身体各三档 |
| 363 | 溪流鱼、观赏鱼 | 两种原身体各三档 |
| 364 | 蝴蝶、蜜蜂 | 两种原身体各三档 |

近档保留完整原装配。中、远档从真实连续组件执行有界边折叠，检查面方向、闭合拓扑、原绑定和实际姿态下的边界。最小体素细件、原点、接口、骨架、用途材质及碰撞声明保持。薄色层、空心衣管和其真实接触区域受到保护，避免毛色埋入身体或裤管内壁穿出。完整源件与简化证明随原生文件保存。

默认姿态下，成人三档分别为 12,760 / 11,196 / 9,330 个三角面，儿童为 13,032 / 11,548 / 9,902；猫为 5,568 / 4,930 / 3,344。鱼鳍和色层受保护，溪流鱼仅从 2,636 减至 2,504，观赏鱼从 2,952 减至 2,866。没有用强行达标的三角预算破坏受保护细节。

每个所选档位另有 `visual-far.glb`，它只应用编辑器既有的原生体素共面合并；这与选择本批中、远 LOD 参数是两件事。全部档位均为显式手选，未实现或冒称距离自动切换、动画更新频率、角色身份、生态与所有权绑定，也没有实测 macOS 帧率。

验证覆盖 180 份实际 GLB、108 次历史父件核对及 22 种父配置；全部导出的包围盒最大误差约 5.75×10⁻⁸ m。119 项相关回归与 3 项新 LOD 测试通过，后者包含全部 60 种原生保存往返。公开 MCP 验证另查全部形态创建、旋转和撤销、八个图册入口、用途换材质及非法参数回滚。完整结果、实际截图范围和保留的失败草稿见批次记录。

当前仍是技术候选。原人物头发、眼部与儿童背包贴合，动物色块形状和部分细节需要在后续效果图打磨阶段处理。全部转换收尾后，从 M001 按图册顺序开始，继续分批提交。
