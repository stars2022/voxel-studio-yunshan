# 完成度与实际限制

此表描述当前代码，不把后续计划当作已完成。

新增的建筑两张参考图使用 `kit-a01`–`kit-a12` / `kit-b01`–`kit-b16` 共 28 项模板，与早期 `ref-*` 分开保留。默认 2cm 原生体素；门扇支持两种静态重建状态，未实现连续动画。细节、实际文件与验形结果见 [ARCHITECTURE-REFERENCES.md](ARCHITECTURE-REFERENCES.md)。

## 缺陷网格：实际处理结论

测试源由框体、薄板、重复/粘连面、窄槽与漂浮碎片组成，源码在 `tests/fixtures.ts`，OBJ 文件随交付保存。

- 自动完成：节点/单位转换、重复占用合并、基础色采样、薄板表面体素化、边与连通片诊断、拒绝不安全的实体填充。
- 不能自动恢复：粘连前各物体的语义边界、低于格距的窄槽、原本不存在的木材/金属/玻璃分类。
- 0.10m 粗格距使部分细片与主体连接；0.05m 能保留更多细节及独立碎片。两个结果都保留供人工检查，不把更细结果称为完全正确。
- 需要人工：检查开口、擦除被膨胀封住的格子，按区域/部件明确赋材质；重要门窗和薄壁建议用参数模板重新建模。

## 用户提供的真实参考与模型

实际 GLB、原始参考图、两档表面转换、实体填充失败、初次高色彩精度失败，以及图鉴参数母版均已保留。对照结论和截图见 [REFERENCE-STUDY.md](REFERENCE-STUDY.md)。新增灯光与 SSAO 为可关闭的显示效果，不改变原生体素；没有假设发光材质会自动照亮周围物体。
