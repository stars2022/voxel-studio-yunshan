# 建筑两张图的原生体素转换

本批对应用户提供的 `参考/庭院建筑模块图鉴-2.png`（A01–A12）与 `参考/立面与细部组件-1.png`（B01–B16）。方法是依据图片解析结构并编写参数化体素规则，不是通用单图三维重建，也没有把 Tripo 网格改名作为体素。

28 件分别保留原生体素网格、材质 ID、米制原点、部件范围、安装接口与生成参数。默认格距 0.02 米，Y 轴向上，正面为 −Z。图片无法确定的背面、尺寸、支撑厚度由本批显式设计。现有早期 `ref-*` 模板和家居资产不覆盖；新模板名是 `kit-a01` 到 `kit-a12`、`kit-b01` 到 `kit-b16`。

## 运行与打开

```sh
npm run build
npm start
```

编辑器：`http://127.0.0.1:4317/?library=1&flat=1&view=perspective`。在「参考图鉴 · 素色实模」选择建筑主体或立面细部，可打开两张总览或任意单件。主视图采用基础色与固定朝向面明暗，材质纹理、反射、发光和场景灯光关闭。

```sh
npm run produce:architecture
npm run verify:architecture
```

生成器写入带时间编号的新文件，不覆盖旧项目。`projects/architecture-index.json` 指向当前批次，`artifacts/architecture/latest.json` 记录路径、哈希和实测数据。每个导出目录含 `visual.glb`、`voxels.ysvox.json`、`collision.json`、`interfaces.json`、`atlas.png` 和 `atlas.json`。

## 结构与参数

- 屋面使用连续的量化高度表面，叠瓦、瓦垄、脊檩、檐下椽条都写入体素。转角屋顶只有一张连续壳面，不使用相交屋面填出实心夹层。
- 开间具有柱脚、石柱、金属套箍、木嵌面、灯座、玻璃压条和真实贯穿入口。格栅孔、门洞、桥面通路、花槽土面上方均保留空体素。
- 铺面分缝和砌块分缝具有深度，并保留连续承托。接缝不用贴图伪造。
- 花槽包括槽壁、厚口沿、下沉土层、排水口、分枝和叶簇。
- 支持尺寸重建；入口开间及门楼可调整开口宽高。B02 的 `doorOpen` 为 0/1 两种静态几何状态，尚非连续动画或游戏交互门。
- 2cm 格距为本批验证规格。生成器还接受 1cm / 4cm，受单资产 100 万格和区域预算限制；细化精度并非对所有尺寸均可成功。

MCP 与界面使用同一个 `createAsset` / `regenerate` / `assignMaterial` / `instance` 事务系统。例如先以 `dryRun: true` 提交以下事务，审阅结果后使用返回的 `previewToken` 提交同一请求：

```json
{
  "expectedVersion": 0,
  "requestId": "architecture-b01-example",
  "dryRun": true,
  "commands": [
    {"op":"createAsset","id":"my-window","name":"B01 落地窗","template":"kit-b01","cellSize":0.02,"params":{"width":3.2,"height":2.64,"depth":0.24}},
    {"op":"instance","id":"window-placement","assetId":"my-window","position":[0,0,0]}
  ]
}
```

版本号应以当前项目为准。参数重建会替换母版的手工修改，已有 dry-run 影响预览及整批撤销机制继续适用。

## 验证与范围

`tests/architecture.test.ts` 检查 28 个不同原生结构、无损读写、入口净空、格栅与花槽空腔、静态门状态、接口拼装、版本冲突、失败回滚和整批撤销。稀疏构件的部件包围盒允许较大的空区域；逐格区域修改仍保留原有 200 万候选格限制。

`scripts/verify-architecture.ts` 通过真实 stdio MCP 和独立本地服务打开文件，在浏览器中逐件截图，并实际重新导入 GLB 比较坐标包围盒；结果写入 `artifacts/architecture/verification.json`。A/B 联系表只排版实际 WebGL 截图，没有生成图或预录画面。

2026-10-03 验证批次：`architecture-20261002160234`（文件编号使用 UTC）。完整核心测试 **73 / 73 通过**；28 件默认结构均为单一面连通体，没有悬空碎片。每件完成透视、前、后、顶四个视角检查，共 112 张实际截图；28 个 GLB 全部重导入并核对米制坐标包围盒。MCP 一批修改 48,292 格后界面同步，版本冲突、重复请求、失败回滚、一次撤销和无损保存均通过。另实际点击界面创建模板，确认默认 2cm 格距和预览提交有效。

本轮修正了沿脊高误放的屋檐齿、无背板灯带、脱开的屋脊顶帽、右门拉手朝向与铰接位置，以及粗格距柱角碎片。转角开间增加外角花槽、承托和侧向柱灯；首层开间补齐柱脚小阶。初次几何及报告保留在历史批次中。

额外执行了 4cm 默认尺寸的 28 件连通检查，并修正首层柱脚小灯的量化吸附；这项检查不替代 4cm 的完整视觉验收。交付的 2cm 几何逐件哈希与当前生成器一致。

实测环境为 Apple M3 Pro、18 GiB 内存、arm64、Node 24.19.0；内核版本为 Darwin 27.2.0。28 件合计 **5,005,662 个占用体素**，合面后 **138,556 个三角形**。原生生成加逐件导出耗时 **51.93 秒**。验证浏览器使用 Chromium 153 的 SwiftShader 软件 WebGL，单件网格 Worker 耗时 **18.7–1,294.2ms**、每件 **3–13 个绘制调用**；这些是本机该次采样，不是硬件 GPU 帧率承诺。

`python3 scripts/package-architecture.py` 会校验当前批次、文件哈希和验证结果，然后生成 `artifacts/architecture/云山-建筑两图-28件模型包.zip`，包含 30 个原生文件（28 单件与两组总览）、28 套导出、格式文档、Schema 与实际截图。

这些是 28 项图鉴设计的几何候选，不等同于原始 1,068 项清单里新增 28 个基础母版或已经美术验收。总览中的重复实例不另计资产。没有增加蒙皮、人物动作、通用图像识别、自动 Tripo 语义修复或建筑受力分析；玻璃和灯罩当前以基础色验形。
