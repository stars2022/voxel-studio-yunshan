## 几何验收依据

| 部分 | 应有的结构 | 当前实现与仍需检查的部分 |
| --- | --- | --- |
| 栏杆 | 木扶手、铁柱、柱帽、底脚、连接位置、钉头；杆间留空 | 新建独立体素模板，部件使用不同材质 ID；已验证空隙。比例和连接细节尚待近景检查 |
| 窗前开间 | 石柱、木柱、金属箍、压条、窗框内外退进、门洞 | 新建 2cm 格距模板，门洞真实留空。玻璃表现及轮廓与原图的接近程度尚未视觉验收 |
| 花槽 | 厚口沿、内壁、土层、凹面边框、立体回纹 | 口沿、内腔、凹凸纹样均为体素，不是贴图假洞。未做真实侵蚀和破损求解 |
| 植物 | 枝干、分枝、倾斜叶片、花簇、间隙与高低变化 | 原生体素枝叶与花簇，确定性生成；当前是一种有限的植物造型，非植物学或美术完成度保证 |
| 灯笼 | 墙座、悬臂、吊杆、顶盖、四角骨架、灯罩、底坠 | 各层写入真实网格。光照仍是近似，灯光效果不代替实体骨架 |
| 室内与地面 | 家具、摆件、铺地、墙饰带来的空间层次 | 本轮未重做整套室内与场景陈设 |

所有构件仍是材质 ID 与体素坐标。表面纹理只改变着色，不能改变门洞、碰撞或体素数量；灰模检查仍应能辨认构件层次。原生部件选区仍是包围区域，不是逐格的互斥所有权分组。

## 表面与显示实现边界

材质新增可选 `surface`、`surfaceScale`（米）、`surfaceStrength`。确定性的石材、木纹、拉丝、陶瓦和织物细节同时用于编辑器着色和 GLB 纹理导出；没有修改占用格。GLB 保留基础色、法线、粗糙度纹理。色板图集仍单独导出。

“灯光”开关默认关闭：从最多 30,000 个发光候选格提取岛屿，场景最多使用 8 个无阴影点光源近似照明。可能穿过遮挡，不是 GI；这些预览点光源不导出到 GLB，发光材质正常导出。“辉光”为可关闭的屏幕后处理，默认关闭。新显示路径通过类型构建，但尚未按本轮参考图完成视觉验收。

当前不能把“这些结构已生成并能编辑”表述为“已经达到参考图效果”。下一次应先对照近景检查几何比例、构件连接和疏密，再评估光照与表面。
