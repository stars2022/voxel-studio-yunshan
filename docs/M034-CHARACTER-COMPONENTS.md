# M034：长发、面部毛发与头部穿戴

本批包含 CHAR-089–100 的 12 个清单母版、24 种有限形态。最小发饰、须根和眉梳使用 5 mm 原生体素；发束、编辫、盘髻、布褶和冠环使用真实连续网格。头、头发、胡须、眉毛、帽和冠分别保存。当前为技术候选，人工美术验收为 0。

## 穿戴和真实几何

发型配 CHAR-066 成人头或 CHAR-068 儿童头，稀疏发配 CHAR-069 老年头。儿童发型独立调整纵向比例，同时保留适合实际头宽和耳部的横向腔体。发型包含完整头皮壳；胡须、眉毛、软帽、发冠不包含头部。眉毛安装派生件真正移除原头的两组原生眉毛格，原头母版另存。

软帽套在独立短发 CHAR-085 外，帽底开放；帽布和帽带不是实心堵头。发冠配成人 CHAR-093 的 `crown-seat`，织带外缘在接口平面承托底环。簪槽有真实贯通壁，横簪穿过实际空腔；`removed` 形态同时移除横簪、端止挡、吊绳和流苏，不靠隐藏贴图模拟抽簪。

七个场景保存长发、束发、儿童与老年、面部毛发、软帽、发冠和转头坐姿研究。转头场景保留源头及发型，通过单个 `head` 关节旋转，体素顶点作刚体变换，不重新采样到斜格子上。坐姿身体由 M031 的躯干、上下腿、靴、袖臂和手按实际摆放矩阵派生，旧头与旧发片真正省去，源组件另存；这是静态作者装配，没有座椅或动画。

实际三角面检查包括头皮、耳、眼及原生面部细节，帽与帽内短发，发冠与高髻。CHAR-089–093 和成人长须另在 −30° / 0° / +30° 检查站姿身体及成人坐姿身体；儿童检查独立儿童站姿。此范围不代表所有俯仰、衣装、动态摆动或原游戏受保护净空。秃顶区域、口部间隙和簪槽用真实射线与三角面验证。

## 绑定、导出与材质

每件有真实单 `head` 关节刚性绑定。原生格和连续表面保持绑定姿态权威；GLB 输出 `skin`、逆绑定矩阵、关节索引与权重，接口同时保存绑定及姿态端口。独立 glTF 求值核对导出边界。近远档仅合并原生共面表面，连续发束和服饰网格保留。

新增八个用途角色：`hairOrnament` 金属、`hairGem` 零发光玻璃、`headWrap` 帽布、`headWrapBand` 帽带、`beardHair` 胡须、`browHair` 眉毛、`sparseHair` 和 `sparseHairRidge` 稀疏发层。发色与织带色通过材质方案替换，不增加清单母版。全部角色组件非碰撞；净空结论来自独立几何检查。

原角色源码、尺寸矩阵、面部图集、骨骼和控制器未收件。没有软发动力学、软皮肤权重、IK 或动作片段；簪拆装参数是两种静态几何形态。Chromium / SwiftShader 实图属于软件 WebGL 验证，不是硬件帧率验收。
