## 实际穿戴与保留来源

婴儿、学龄、青少年、成人 A / B 分别采用既有 CHAR-061 / 063 / 064 / 059 / 060 的独立作者比例，未把成人等比缩小冒认年龄形态。头、发、手足、内搭和鞋来自另存的既有组件，不重复计数。婴儿与青少年保留原年龄身体的中性衣套手足端，绑定到实际腕踝关节；不称为已制作对应年龄的精细手足。学龄和成人使用实际独立手足与成对鞋。

身体安装派生件真正移除旧衣身和袖面。田作短袖保留由原袖身剖分的作者前臂轮廓，改用皮肤用途；这不是原裸体网格。围裙穿戴使用 CHAR-113 上衣和 CHAR-118 长裤，移除被替代的旧身体上下衣面。所有身体原母版另存。

实验外套保存 CHAR-113 原上衣，另建只含可见前衣面、前衬及领圈的内搭派生件。前衣面沿原轮廓重建为 ±27° 扇区；隐藏袖、肩背、织带及全部对应原生扣件一起移除。记录源 ID、删除范围和 `notCatalogMaster`，不回写原件、不计新增清单母版。

初稿曾出现裤腿与长衣下摆相交、完整旧上衣与实验外套相交、围裙颈腰环穿入袖管的问题。下摆改为较扁的圆角截面，并保留裤腿顶部空间；围裙环按真实内搭表面重定位；实验内搭明确替换隐藏分件。初始失败证据随包保留。

23 种站姿形态覆盖 375 组实际三角面关系；七组场景覆盖 275 组衣装与身体、头、发、手足、内搭、鞋的关系。101 处射线检查覆盖领轴、袖口及口袋开口；口袋有真实内腔、独立衬里和底面。连续薄壳封闭且面绕序正确，原生细件具有实际附着面。全部角色材料非碰撞，空碰撞列表不替代穿插检查。三角面采样和边交叉检查不是任意动作的形式化证明。

## 关节、材质与导出范围

衣装使用 16 个作者关节，每个分件归一个关节。默认肩外展成人、学龄及青少年为 8°，婴儿为 18°，以避开短肢宽躯体的裤腿。手部挂接另加朝向关节。原生格保持绑定姿态，显示与导出通过关节矩阵变换，不旋转后重新栅格化。

七组场景为年龄衣装、制服、劳动与田作、医疗、服务与围裙、有限姿态、实验外套双体型。姿态场景只验证 CHAR-127 成人 A 肩外展 45°、CHAR-130 成人 A 有限行走；行走为肩前后 15°、髋前后 12°及单膝 10°。长衣与其余组合仅站姿。没有坐姿衣装通过结论，也没有软布、软权重、IK、动作片段或原骨架控制器绑定。

GLB 保存实际 skin、逆绑定矩阵、关节索引和权重，并独立求值导出姿态再核对边界。近远档仅合并同关节的原生共面，连续网格保持不变。全部 23 种形态及七组装配分别输出原生文件、GLB、材质图集、接口/绑定和空碰撞声明。

新增 15 项用途：婴儿布、学堂布、制服布、耐磨布、田作布、医疗布/饰边、实验外套布、服务衣布、围裙布、金属护板、软垫、织入标识、身份扣塑料底及印墨。全库 300 个角色，新增 ID 312–326，全部非碰撞零发光。材质按 256 + 44 条在同一事务创建；保留外来 ID、失败回滚和一次撤销验证。衣料、金属、塑料与印墨可独立替换，不因颜色接近混用。
