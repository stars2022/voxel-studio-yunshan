# M030：基础体素块件、连续坡面与天空贴图

按用户 2026-10-04 的明确修正，体素用于最小基础块件，斜面、坡面和曲面允许正常网格，天空和星空使用贴图。此前批次“所有形体必须按完整网格制作”的限制不再适用于新资产。

本批含 12 个清单母版、25 种参数形态。ENV-086 院廊支撑、088 路肩、091 边沟、094 地坪、096 花槽树池、097 容器、098 座椅、104 景观灯，以及 110 天空、112 太阳、113 月亮、114 星点。当前为技术候选，待人工美术验收。

| 内容 | 原生数据 | 通用导出 |
| --- | --- | --- |
| 基础块件 | `Asset.chunks` 与材质 ID | 带用途材质的 GLB、固体占用格 |
| 连续路肩坡面 | `Asset.meshes` 的米制顶点、法线、UV、索引 | 相同顶点与三角面的 GLB / 碰撞网格 |
| 天空、太阳、月亮、星空 | `Asset.sky` 的参数、用途映射、保存时刻 | RGBA PNG、嵌入贴图的 unlit GLB |

天空贴图不使用体素填充。星点由固定种子的 600 个采样点生成一张透明贴图，共一个组件；不会创建 600 个清单模型。月面是作者绘制规则生成的斑纹，不是天文观测图。天空材质的基础色与不透明度独立可换，使用正确的 sRGB 贴图采样；不把实体 PBR 的灯光、粗糙度和表面纹理误用于天空。

编辑器选择天空资产后可在属性栏设置预览时刻、背景天气和可见度。预览随相机移动，退出后恢复原观察位置，不改写保存的资产。GLB 是保存时刻的快照。原描述的 14000、68、38 米参数暂按作者半径解释，原源码未收件，不能把这解释当成已经核实的原尺寸含义。

ENV-088 提供 4/8 米作者路床宽度及填方、挖方、高架接边，共六种形态。最小块件保留体素，坡面为真正连续的闭合三角网格。高架形态中间保留六米通道，交通铺装属于另一个辅助安装件。通用占用检查器只检查体素部分，会明确提示连续网格的检查范围；独立验证检查闭合性、导出一致性和总览实例的实际边界分离，不把体素代理冒充坡面。

五组安装样件包括院廊、路肩、排水沟、种植容器和休憩庭院。土壤按实际容器内腔生成，植物复用现有 ENV 母版并核实根部接触；孔篦孔洞、容器排水孔与通路留空。景观灯的硬玻璃和光学芯分开，默认零发光；长椅尚未绑定角色的坐姿、权限或使用点。

证据目录：`artifacts/atlas/atlas-20261004064850`。原生文件在 `projects/atlas-20261004064850-*.ysvox.json`；每件导出在 `projects/production/atlas-20261004064850/exports/`，包括基础、材质、远景 GLB 以及天空 PNG。`validation.json` 汇总最终测试与截图。浏览器截图使用 SwiftShader 软件 WebGL；未接入原游戏地形、时钟、供电或控制器。
