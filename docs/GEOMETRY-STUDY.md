# 构件几何研究：同格距、同基础色比较

本轮依据用户提供的开间近景和四构件检查图，研究可以写进真实体素的造型细节。结论是：**格距相同的资产，仍会因为截面、连接、退进层次和植物疏密而出现明显差别。** 提高分辨率不会自动生成这些设计。

所有对比构件均使用 **0.02m 格距、Y 向上、原材质 ID 和基础色**。预览关闭纹理、法线贴图、反射、发光、透明、场景照明、阴影、AO 和后期，只保留固定面朝向明暗以辨认形体。玻璃在此模式下是不透明的青色。截图来自本地编辑器的实际体素网格，不是图片生成结果。透视观察方向一致，每个资产自动取景，因此边界变化会影响画面中的大小。

## 观察、修改与边界

| 构件 | 参考图中可观察的结构 | 本轮落到原生体素的修改 | 仍有差距 |
| --- | --- | --- | --- |
| 开间 | 砖檩饰牌、窗压条、玻璃角线、带安装座的把手 | 添加叠层饰牌和回纹；玻璃角线用同平面的材质 ID 嵌色；把手改为两个支座和留空的握杆；灯匣增加端部收口 | 柱帽与石缝仍偏规则，毫米级倒角和复杂纹样未做 |
| 栏杆 | 木扶手不是单一方条，连接位置有套箍，柱帽和底脚有截面变化 | 扶手增加阶梯截面；各段在柱间插入套箍；柱帽、石脚分层；指示格嵌入柱面 | 2cm 格距下铆钉、卡件仍显粗；未做真实榫卯强度求解 |
| 花槽 | 口沿与内壁退进、凹面框线、回纹；植物有成簇的枝叶和局部空隙 | 改成阶梯口沿、连续面板；填实土层；分簇栽植，改变叶片方向、宽度、倾角和高度；枝干保证面连通 | 叶片仍是有限的程序化造型，花序较简单；没有达到参考图的植物丰富度 |
| 灯笼 | 墙座、悬臂、骨架、灯罩、顶盖和底坠各有连接关系 | 薄灯罩围出真实内腔；叠层盖与连续底坠；墙座、螺钉和斜撑；新增实际墙装接口 | 小五金比例仍受格距限制，未做高级透射或半透明灯罩渲染 |

参考图不能唯一确定尺寸、背面或实际安装构造。本轮沿用旧模板的米制尺寸作为设计假设，没有把图片上的尺寸文字当成测量结果。图片中的表面斑驳和高光未作为本轮几何修改；没有靠新增纹理或灯光弥补轮廓问题。

## 体素与结构实测

| 构件 | 原版占用格 | 研究版占用格 | 原版 → 研究版六邻接连通块 | 研究版合并四边面 |
| --- | ---: | ---: | ---: | ---: |
| 开间 | 393,573 | 393,799 | 1 → 1 | 4,386 |
| 栏杆 | 10,324 | 10,377 | 1 → 1 | 624 |
| 花槽 | 19,067 | 40,037 | 39 → 1 | 5,525 |
| 灯笼 | 1,440 | 1,166 | 1 → 1 | 214 |

这里的连通块按共享面的六邻接计算。原花槽的一部分枝叶仅通过棱角相接，土层也只有悬空薄片。新枝干使用逐面连续路径，叶片仅保留与叶脉连通的采样格，土层填到根部。全部四构件现在各为一个连通整体。连通性不等同于承重可靠性。

花槽新增占用格包含大量内部土壤，不能用数量翻倍说明画面细节翻倍。开间和栏杆只增加少量格子也能改善构造；灯笼挖出内腔后，格子更少。体素数量不是美术质量指标。

花槽与灯笼另通过 **1cm、2cm、2.5cm** 格距下的连接与内腔测试。这不表示整栋建筑可以直接改成 1cm：当前开间整块改为 1cm 会超过候选格预算，若要细化应先拆成独立细部组件。2cm 网格不能准确表达几毫米宽的螺钉或倒角。不同格距的安装仍需通过现有兼容检查，未放宽接口规则。

- [重启恢复](../artifacts/geometry-study/restart-verification.json)：主项目 v44 文档及原撤销 / 重做记录无损恢复。
- [加入当前项目记录](../artifacts/geometry-study/installed.json)：一个 MCP 事务添加四个 `study-*` 母版，v44 → v45；原资产、材质、风格、选区、组合及实例逐项保持一致。后续用户编辑可继续增加版本。
- [当前编辑器读回](../artifacts/geometry-study/live-browser.json)：确认研究版花槽实际显示，几何散列与离线研究结果一致。
- 保存的原生项目完整读回；花槽 GLB 重新导入后的尺寸与坐标误差小于 1e-6m。

实拍过程中发现并修复了渲染同步问题：后台合面尚未完成时就缓存了内容散列，快速提交 / 撤销 / 重做会让后续刷新误认为几何可用，出现空资产视图。现在串行提交网格缓存，跳过过时快照，并仅在当前版本网格完成后宣布就绪。修复前的 [空视口失败截图](../artifacts/geometry-study/failure-empty-bay.png) 保留用于追溯；它不是交付效果图。第一次只检查文档同步不足以发现该问题，后续增加了网格、版本及像素断言并重新截图。

本轮没有重跑较早的整套导入风险、取消长任务等 25 项端到端场景；其历史结果仍见原验证文档。本轮可主张的是上述实际重跑的核心与专项检查。

## 使用与复现

当前编辑器：[研究版花槽 · 素色](http://127.0.0.1:4317/?asset=study-planter&view=perspective&flat=1)。同库还包括 `study-bay`、`study-railing`、`study-lantern`。它们是独立研究母版，没有替换民居实例。原 `atelier-*` 母版保持保存时的格子；手动点击参数重建将使用新版生成器，界面仍会预览并警告替换手工编辑。

- [独立原生对照项目](../projects/geometry-study.ysvox.json)：四个原版和四个研究版。
- [包含原民居的主项目另存为](../projects/geometry-study-with-house.ysvox.json)。
- [花槽视觉 GLB](../projects/exports/geometry-study-planter/visual.glb)、[可编辑体素数据](../projects/exports/geometry-study-planter/voxels.ysvox.json)、[碰撞数据](../projects/exports/geometry-study-planter/collision.json)、[接口](../projects/exports/geometry-study-planter/interfaces.json)。导出的 GLB 继续保留原材质属性；素色开关只作用于预览，不改原生材质。

在 `voxel-studio` 内运行：

```sh
npm run build
npm test
npx tsx scripts/geometry-study.ts
```

研究脚本使用保存的 `artifacts/geometry-study/before-state.json` 基线，在独立目录和回环端口 4337 中运行，再关闭测试服务。它不会改写主项目。`--install` 才通过本地 4317 的 MCP 服务添加研究母版；相同 ID 已存在则拒绝覆盖。修改生成器源码后需重启主服务以载入新版，再安装。不要重复安装覆盖用户编辑。
