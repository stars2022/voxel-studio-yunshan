`produce:atlas` 无参数会重建所有已实现的图册配方；`--sheets=` 可选择批次。它使用与 MCP/UI 相同的 Engine、命令、dry-run、提交和项目校验；新文件带时间戳，保留旧版，并原子更新索引。生成过程中发现意外孤立结构或导出坐标漂移会失败，不更新正式索引。`--metal` 是本机 macOS 硬件验证选项，使用已安装的完整 Chromium；其他环境可省略，但必须查看报告中的实际 WebGL 渲染器。预览与 MCP 验证分别运行在 4345、4346、4347、4348、4349、4350、4351 端口的独立项目目录，不替换正在使用的文档。

`projects/atlas-production-index.json` 列出全部有效单件和总览。当前为 192 份单件加 16 份总览，共 208 份有效库文档，另附服务翼、旧楼梯井与侧开门/纸灯原生拼装样例。总览只放置同一母版，不增加母版数。M001–M009 有效文件为 `atlas-20261003063047`，M010 为 `atlas-20261003072623`，M011 为 `atlas-20261003081509`，M012 为 `atlas-20261003092028`，M013 为 `atlas-20261003104805`，M014 为 `atlas-20261003120646`，M015 为 `atlas-20261003124439`，M016 为 `atlas-20261003132803`；M015 首轮为 `atlas-20261003124003`；M014 首轮 `atlas-20261003115837`、M013 初次版本 `atlas-20261003104125`、M012 首轮 `atlas-20261003085620`、M011 初次版本 `atlas-20261003080834`、两次 M010 制作及全部旧版本完整保留；单件的 `visual.glb`、`voxels.ysvox.json`、`collision.json`、`interfaces.json`、`atlas.png`、`atlas.json` 位于对应 `projects/production/<批次>/exports/<ID>/`。

BUILT-096 是2.4m深、2.8m宽的阳台板和木支托；BUILT-097 是独立1.1m扶栏，含五根细竖栏、木扶手和独立玻璃填片。两个20mm母版与有真实承托的验证墙拼装。BUILT-098 为单侧7m石接台，另一侧是180°同母版实例，中央留2m入口；不能把两个实例算两个资产。BUILT-099 是两片3m宽、5.6m深的店檐，中间留4m；BUILT-100 仅一根0.4m木芯、3.6m总高的柱，四次实例化承托店檐。

BUILT-101 是2.2m宽的实体灯箱。塑料透光板用 `signDiffuser`，印墨用 `printedDark`，灯芯用 `warm`，木金属框各归本类，不借用屏幕、纸罩、玻璃或相近颜色。简化茶壶和茶字是静态体素图形，不是原游戏真实店名；40mm网格使印墨厚度和形体仍偏粗。背光层已分类，但透明混合没有真实灯箱透射或全局照明。

BUILT-102 保留两根2.8m方筒、8m高度，中心距7.2m。两条2m宽烟道上下贯通，陶质内衬用 `flueLiner`，外砌石、砂浆、木帽、防水膜和金属泛水各用独立ID。BUILT-103 是五列双排临街木架，中央两列从3.2m以上起，共八根落地柱，门下净空保持开放；没有荷载、烟气、热学、楼层或人物控制器集成。
